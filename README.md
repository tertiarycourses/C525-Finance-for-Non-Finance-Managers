## About the course

This course helps managers without a finance background read financial statements, use ratios and cash-flow analysis, review historical performance, and evaluate investment suitability. The activities use fictional companies and figures for classroom practice.

## Learning outcomes

By the end of the course, learners can outline the process of financial statement analysis, assess an organisation's financial health from financial analysis, and define indicators for investment suitability.

## Topics covered

1. The different financial ratios
2. Profitability Analysis
3. Cash Flow Analysis
4. Projected financial and cash-flow statements
5. The process of financial statements analysis
6. Use financial analysis to determine the health of an organisation
7. Evaluate organisation's historical financial performance
8. Investment suitability based on financial analysis
9. Analysis for the financial services industry
10. Benchmarking of financial performance against industry
11. Use Capital Budgeting to evaluate potential investment returns
